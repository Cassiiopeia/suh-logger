# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone, in public or in private, for any reason.

## Reporting

Report unacceptable behaviour privately through a [GitHub security advisory](https://github.com/Cassiiopeia/suh-logger/security/advisories/new) (it is visible only to maintainers), or contact the maintainer [@Cassiiopeia](https://github.com/Cassiiopeia) on GitHub. Reports are kept confidential.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that violate this code, and may ban contributors temporarily or permanently.
